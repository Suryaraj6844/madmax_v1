MADMAX Player Lab (ZokoAnime + AnimeEmbed)

DO NOT double-click index.html. Embedded players refuse to load from file:// pages.

Run:   ./start.sh        (Linux/macOS)   |   start.bat (Windows)
Open:  http://localhost:8000

If a player is still blank: use "Open in new tab", or turn off Brave Shields for localhost.
